# R42GY Background WebView2 Fast Media Observer Runtime

Marker: `YTCE_R42GY_BACKGROUND_WEBVIEW2_FAST_MEDIA_OBSERVER_RUNTIME`

Status target: `PASS_R42GY_BACKGROUND_WEBVIEW2_FAST_MEDIA_OBSERVER_RUNTIME`

## Scope

R42GY adds the runtime bridge for the Media-window fast path:

1. call an explicitly supplied background WebView2 media observer backend per source link;
2. normalize observed media/resource events into the R42GV visible-browser media observation store;
3. project that store through R42GW into the unified `All / Images / Videos` Media window package tree;
4. keep the Review window separate.

## Important boundary

R42GY is not a hidden scraper. It does not add hidden X API scraping, login automation, token/cookie extraction, CAPTCHA/challenge bypass, paywall/access-control bypass, source-role assignment, review-window rewrite, or YouTube capture-engine changes.

When login, consent, challenge, CAPTCHA, access-control, or insufficient material is detected, the runtime returns:

`ESCALATE_R42GY_VISIBLE_WEBVIEW2_OR_EDGE_HUMAN_CONFIRMATION`
