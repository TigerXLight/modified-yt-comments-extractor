# Profile/Media Database User Quickstart V76J

1. Switch DATABASE mode on.
2. Use **Plan existing folder import** to review a pasted folder-tree list.
3. Write a batch-preview JSON only after reviewing the candidate sources/profiles.
4. Load that explicit batch JSON into the Database workbench.
5. Use the review lanes for source-chain gaps, disputed framing, unknown source roles, and parser warnings.
6. Materialize only into a disposable/test root first.
7. Apply reviewed folder operations only when the exact source and destination paths are shown.
8. Reconcile the batch preview after reviewed rename/move operations.

The workflow is designed to keep media/source claims reviewable without treating every file as evidence or making sensitive identity assumptions.
