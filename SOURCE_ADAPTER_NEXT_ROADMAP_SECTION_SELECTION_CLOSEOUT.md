# Source Adapter Next Roadmap Section Selection Closeout

`source_adapter_next_roadmap_section_selection_closeout_v1` consumes the Release Regression Next Roadmap Closeout package and converts the final source-adapter handoff into concrete next-roadmap section selections, work orders, Codex prompt queue rows, regression command groups, and a ready handoff for the next implementation batch while preserving the `KEYS/ACCOUNTS` credential-reference label.

The closeout keeps the shared source-adapter runtime work connected to actual follow-on implementation work: GUI/controller hardening, provider execution activation, priority site fixture authoring, operator-approved live smoke receipt capture, regular regression promotion, and documentation/handoff refresh.

Generated artifacts include:

- `source_adapter_next_roadmap_section_selection_index`
- `source_adapter_next_roadmap_work_order_manifest`
- `source_adapter_next_roadmap_codex_prompt_queue`
- `source_adapter_next_roadmap_regression_command_manifest`
- `source_adapter_next_roadmap_ready_handoff`
- `source_adapter_next_roadmap_section_selection_operator_summary`
