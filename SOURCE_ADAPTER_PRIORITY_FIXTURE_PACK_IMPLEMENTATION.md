# Source Adapter Priority Fixture Pack Implementation

Implements the next runtime step after GUI/provider activation.

This module consumes `source_adapter_runtime_gui_provider_implementation` output and builds execution-ready priority fixture pack artifacts for article/news pages, social posts/threads, comments/replies threads, media/transcript sources, and archive-provider receipts. The implementation records local fixture dispatch receipts through the registered runtime controller/provider matrix, keeps the `KEYS/ACCOUNTS` reference selector as the credential surface, and prepares operator-approved manual smoke rows for named sites.
