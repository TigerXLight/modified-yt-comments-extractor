# MSN Source Adapter Final Readiness Badge

This layer produces a conservative badge for the MSN source adapter state. It does not equate no-network tests with real live completion.

Allowed badges:

- `READY_FOR_LIVE_EVIDENCE`
- `RC_LOCKED_PENDING_LIVE_EVIDENCE`
- `PROMOTION_BLOCKED`
- `COMPLETE_WITH_POSITIVE_LIVE_EVIDENCE`

The COMPLETE badge is only available when a positive manual/live evidence result is present and validates.
