# Source Adapter GUI Online ASR Button Contract Runtime

This implementation milestone adds `source_adapter_gui_online_asr_button_contract_runtime` as a callable runtime surface for the shared Source Adapter pipeline.

It covers GUI Online ASR button contract rows for adjacency to Local ASR, identical orange styling metadata, cog affordance, and routing to online ASR profiles.

The milestone preserves the `KEYS/ACCOUNTS` label, carries credential references as identifiers/redacted hashes only, records receipt-required rows, and keeps provider/network execution behind explicit operator-approved runtime calls.
