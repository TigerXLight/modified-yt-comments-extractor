# MSN Source Adapter Status Wording Lock

Use this wording consistently:

- Repo-side no-network tooling can be **verified**.
- Live MSN behavior is **not complete** until a positive manual/live evidence result exists.
- A working fixture means the code path is covered; it does not prove future MSN layout stability.
- MSN can be the captured platform/republisher while the visible publisher, image credit, source credit, and original source remain separate.
- Reposted media or agency/family/publisher repetition does not become primary evidence merely because it appears on MSN.

Allowed final statuses:

- `INCOMPLETE_TOOLING`
- `READY_FOR_LIVE_EVIDENCE`
- `RC_LOCKED_PENDING_LIVE_EVIDENCE`
- `PROMOTION_BLOCKED`
- `COMPLETE_WITH_POSITIVE_LIVE_EVIDENCE`
