# Source Adapter GUI KEYS Accounts Panel Runtime

This implementation milestone adds `source_adapter_gui_keys_accounts_panel_runtime` as a callable runtime surface for the shared Source Adapter pipeline.

It covers GUI KEYS/ACCOUNTS panel rows for added-provider search, full-catalogue add-provider search, provider metadata display, and safe account references.

The milestone preserves the `KEYS/ACCOUNTS` label, carries credential references as identifiers/redacted hashes only, records receipt-required rows, and keeps provider/network execution behind explicit operator-approved runtime calls.
