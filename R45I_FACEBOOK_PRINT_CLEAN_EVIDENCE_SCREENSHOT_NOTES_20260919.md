# R45I Facebook print-clean evidence screenshot

R45I adds the screenshot method that should be used after R45H has expanded/loaded the Facebook comments.

The method is deliberately two-stage:

1. **Interactive expansion stage**: R45H/R45G opens the real logged-in Facebook post, keeps the modal/comments UI clickable, and expands visible `View hidden comments`, `View hidden replies`, replies, and `See more` controls.
2. **Static evidence stage**: R45I takes the already-loaded/exported comments and builds a print-clean comments-only evidence page. This page has no Facebook chrome, no modal scroll trap, no feed/sidebar, and no floating controls. It is intended for full-page or tiled screenshots, similar in spirit to Print Edit WE output.

R45I does not use hidden Facebook APIs, cookies, tokens, profile-file parsing, login automation, or remote media downloads.
