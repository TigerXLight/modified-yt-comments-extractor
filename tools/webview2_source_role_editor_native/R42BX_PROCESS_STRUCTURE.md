# R42BX Native WebView2 Source-Role Editor

- Warm WebView2 helper/server remains in use.
- Native toolbar is a real WinForms toolbar outside the web page.
- Toolbar uses explicit top-row bounds. WebView2 is explicitly positioned below it, so Wayback's own header is not covered.
- Source navigation is dropdown-only; previous/next arrow buttons are removed.
- Project PNG Icons8 artwork is owner-drawn into fixed icon buttons.
- Resize handling is immediate and fit-to-width.
