# MSN Source Adapter Live Evidence Template

This document describes the JSON template generated by `source_msn_adapter_live_evidence_template.py`.

The template is designed to be filled after a manual/live MSN validation run. It is not a replacement for running the capture. It records the operator's observation evidence in a structured form.

## Important rule

Do not set the adapter to complete unless the live evidence is positive. A self-test can prove the code path is functional, but not that MSN live behaviour passed on a real page.

## Required fields

The generated JSON includes:

- `schema_version`
- `artifact_kind`
- `target_url`
- `article_output_folder`
- `operator`
- `checked_at_utc`
- `operator_signed`
- `checks[]`

Every required check should be set to `PASS` only after a real output folder has been inspected. Use `PARTIAL`, `FAIL`, or `NOT_APPLICABLE` when appropriate.

## Required checks

The default template includes required checks for article extraction, comments export, profiles export, offline viewer, archive honesty, media registration, media status records, source-chain separation, final reports, and prevention of false completion claims.
