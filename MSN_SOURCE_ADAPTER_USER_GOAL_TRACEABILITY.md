# MSN Source Adapter User Goal Traceability

This document locks the original MSN goal to explicit repository checks.

## User goal

1. Article extraction and comments extraction.
2. Offline webpage viewer / archive output.
3. Download or register images and video content with honest media status.
4. Preserve source verification, source roles, and source-chain gaps.

## Purpose

The traceability generator maps each goal to expected repository modules, expected output evidence, and the final live-evidence boundary. It is intentionally conservative: repository coverage can be complete while live MSN completion remains pending until a positive manual/live evidence result is supplied.
