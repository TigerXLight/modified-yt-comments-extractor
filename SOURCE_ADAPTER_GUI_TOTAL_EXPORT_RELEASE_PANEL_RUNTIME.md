# Source Adapter GUI Total Export Release Panel Runtime

This implementation milestone adds `source_adapter_gui_total_export_release_panel_runtime` as a callable runtime surface for the shared Source Adapter pipeline.

It covers GUI Total Export release panel rows for source appendices, package builds, release delivery, file-library publishing, and acceptance.

The milestone preserves the `KEYS/ACCOUNTS` label, carries credential references as identifiers/redacted hashes only, records receipt-required rows, and keeps provider/network execution behind explicit operator-approved runtime calls.
