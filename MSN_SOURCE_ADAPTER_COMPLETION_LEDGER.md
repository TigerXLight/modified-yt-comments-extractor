# MSN Source Adapter Completion Ledger

This is the stable index of the MSN adapter completion layers.

## Core chain

1. Manifest/provenance
2. Readiness gate
3. Release report
4. Final validator
5. Media download workflow
6. Total package builder
7. Manual validation intake
8. Done gate and operator smoke pack
9. Acceptance suite
10. Operator final runner
11. Live result reconciler
12. Closeout orchestrator
13. Final lock/regression/evidence pack
14. Final evidence seal and completion snapshot
15. Release-candidate lock and completion ledger

## Rules retained

- MSN is a republisher surface unless the original source is independently located.
- Visible publisher/source credit and original source are different fields.
- Media candidates are not downloaded media unless the local file/hash/status exists.
- Strict WACZ remains experimental/partial unless validated in the supported viewer.
- Repeated media/agency/family/authority claims do not become primary source evidence merely by repetition.
