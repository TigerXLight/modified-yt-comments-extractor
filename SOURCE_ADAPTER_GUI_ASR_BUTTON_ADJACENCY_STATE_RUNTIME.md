# Source Adapter GUI ASR Button Adjacency State Runtime

This implementation milestone adds `source_adapter_gui_asr_button_adjacency_state_runtime` as a callable runtime surface for the shared Source Adapter pipeline.

It covers GUI ASR button adjacency state rows for Local ASR and Online ASR placement, identical action-button styling metadata, cog affordances, and profile routing.

The milestone preserves the `KEYS/ACCOUNTS` label, carries credential references as identifiers/redacted hashes only, records receipt-required rows, and keeps provider/network execution behind explicit operator-approved runtime calls.
