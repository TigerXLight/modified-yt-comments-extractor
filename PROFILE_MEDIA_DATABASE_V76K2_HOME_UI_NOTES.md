# V76K2 HOME UI Notes

## Buttons

Use common-user labels:

- `DATABASE` toggle: ON/OFF HOME repository mode.
- `SAVE`: save/update reviewed folders and metadata to HOME.
- `Add / Import`: add source material or internal import packages.
- `Unload`: remove current import from the view without deleting anything.
- `Plan folder import`: preview an existing folder tree before saving.
- `Review moves`: review folder moves/renames.
- `Update saved index`: reconcile the saved internal index after reviewed folder changes.

Avoid common-user labels:

- `Materialize`
- `Load batch JSON`
- `Clear batch`
- `Profile rows`

## File row policy

Do not add a large dropdown to every file row.  Prefer:

- shortened filename with tooltip/full path on hover
- automatic website/source recognition where obvious
- small Online/Offline selector only when source location is ambiguous
- pressed/grey author/Internal Media button for user-created/captured/scanned material

## Left sidebar

Move YouTube-specific filters toward a YouTube settings/options window.  Use the left database area for HOME summary counts: Primary, Secondary, Tertiary, Persons, Review.
