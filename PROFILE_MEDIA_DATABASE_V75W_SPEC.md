# V75W Profile/Media Database Index Pack

V75W adds a read-only index builder for Profile/Media Database mode.

## Purpose

The index is built from explicit case batch JSON files, not by scanning folders. It gives a fast database-level view of:

- cases;
- global profile names;
- case-local profile rows;
- source rows;
- source buckets;
- source roles;
- source-chain gaps;
- disputed framing;
- parser warnings.

## Safety boundaries

V75W does not:

- scan folders;
- create folders;
- move folders;
- rename folders;
- copy media;
- download media;
- classify automatically;
- infer sensitive identifiers.

All rows are derived from explicit JSON payloads already provided by the user or generated by the safe demo helper.
