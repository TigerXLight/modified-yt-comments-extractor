# Source Adapter Priority Site Pack Execution Closeout

This closeout consumes the shared runtime fixture smoke final closeout package and turns it into named priority site fixture packs, local fixture execution plans, operator-approved manual smoke rows, and roadmap coverage closeout metadata.

It keeps one shared pipeline for article/news pages, social post or thread evidence, comments/replies threads, media transcript or ASR sources, archive provider receipts, and government/register pages. Site-specific work is represented as fixture pack mapping, artifact roles, source URL patterns, and expected receipt fields unless a future extraction surface genuinely needs custom code.

KEYS/ACCOUNTS credential lookup remains represented by credential references and redacted hashes in receipts.

The produced handoff is ready for local fixture authoring, local fixture execution, and operator-approved named-site smoke execution.
