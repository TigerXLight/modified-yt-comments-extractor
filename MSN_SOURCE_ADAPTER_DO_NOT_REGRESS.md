# MSN Source Adapter Do-Not-Regress Notes

Preserve these behaviours in later work:

- MSN is a captured/republished surface, not automatically the original source.
- Visible publisher/source credit must remain separate from the MSN URL.
- Visible media credit must remain separate from original media/source proof.
- Comments/profile export must preserve profile links, account statistics when captured, nesting, deleted placeholders, and comment vote fields.
- Offline archive status must be honest: local rendered HTML can be viewable, WARC can be partial/useful, strict WACZ can remain experimental when the replay tool does not support that package profile.
- Media candidates and download status must be recorded even when a media download is skipped, blocked, unsupported, or manual-only.
- No tool may promote a real MSN page to complete without positive manual/live evidence.
